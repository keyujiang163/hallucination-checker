## 二、统一 3 件套(所有笔记/商品/文章都用)

### 1. 封面公式(5 种轮换)

| 类型 | 公式 | 适用 |
|---|---|---|
| **对比图** | 左旧痛点 vs 右新方案 | 工具类最爆 |
| **数字列表** | "30 个精品 skill" / "¥999 一次" | 流量类最吸睛 |
| **场景截图** | 飞书消息截图 + 圈出关键点 | 真实案例最可信 |
| **emoji 网格** | 5×6 = 30 卡片(已亮 5 + 规划 25) | 完整列表最直观 |
| **痛点大字** | "代码翻车救命神器🛟" + 工具名 | 单 SKU 最聚焦 |

### 2. 标题模板(5 段公式)

```
[数字/emoji][痛点/对比][核心价值][emoji 钩子]
```

✅ 合格示例:`3 个 AI 神器👩‍💻告别加班 周报日报一键喊`
❌ 不合格示例:`AI 工具推荐`(太泛,无钩子)

### 3. 标签词表(5-10 个/篇,主 3 + 长尾 7)

```
主标签(3,流量最大):
  #AI工具  #效率神器  #打工人必备  #程序员日常  #副业

长尾(7,精准搜索):
  #飞书 #日报周报 #上班摸鱼 #职场干货 #职场工具
  #时间管理 #开发者 #技术分享 #debug #自动化
  #Claude #GPT #OpenClaw #订阅
```

**标签选取规则**:每篇主标签从「主标签池」取 3 个,长尾按 skill 所属类别(飞书/创作/开发/变现/效率)取 7 个。

## 三、引流路径图(每步配话术)

```
小红书笔记 → 闲鱼链接 → 飞书群沉淀 → 订阅/续费
     ↓           ↓            ↓             ↓
   种草        成交         私域          长期
```

### 步骤 1:小红书 → 闲鱼

**话术**:
- 笔记末尾:"完整 skill 见闲鱼同名,自动发货 1 分钟"
- 评论置顶:"扣 1 送试用链接(限前 20 名)"
- 个人简介:"30 个精品 skill 合集 ¥999 → 闲鱼搜索 `OpenClaw`"

### 步骤 2:闲鱼 → 飞书群

**话术**:
- 闲鱼自动发货附文:"加飞书群免费答疑 + 季度更新,群二维码:…"
- 商品详情页底部:"拍下后 24h 内私聊拉群"
- 客户感谢语:"进群请发闲鱼订单截图,管理秒过"

### 步骤 3:飞书群 → 订阅

**话术**:
- 群欢迎语:"欢迎 🎉 群福利:① 季度更新 30 个 skill;② 1v1 答疑;③ 优先推新工具"
- 月度推:"30 个 skill 已更新 6 个,老主顾 ¥299/年续费立省 ¥300"
- 季度复盘:"这季新增 10 个 skill,老板数数值不值"

## 五、转化跟踪表(每天 18:00 拉一次)

| 指标 | 数据来源 | 计算方式 | 健康线 |
|---|---|---|---|
| 笔记曝光 | 小红书后台 | 7 天日均 | > 500 |
| 笔记互动率 | 小红书后台 | (赞+藏+评)/曝光 | > 5% |
| 闲鱼拍单 | 闲鱼后台 | 7 天日均 | > 1 |
| 闲鱼客单 | 闲鱼后台 | 7 天均单 | > ¥19 |
| 飞书群新增 | 飞书群 | 7 天日均 | > 0.5 |
| 订阅续费 | 飞书群/闲鱼 | 月续费率 | > 30% |

**自动化方案**(主会话可接力出):
1. `tools/fetch-xhs-stats.js` — 抓小红书后台(需 cookie)
2. `tools/fetch-xianyu-orders.js` — 抓闲鱼订单(需 cookie)
3. `tools/fetch-feishu-members.js` — 抓飞书群人数(OpenAPI)
4. 每天 18:00 cron 拉数据 → 写 `memory/YYYY-MM-DD-tracks.md` → 飞书群汇报

🟡 **限制**:抓 cookie 必须老板手动登录一次,token 走 env-vault 不进 SOP(老板自己判断合规性)。
